# 蛇货战绩数据大屏 - 完整功能列表

## 🎯 专业大屏功能

### 1. 全屏模式
- **按钮位置**：右上角 "🖥️ 全屏"
- **快捷键**：F11
- **功能**：一键进入/退出全屏，适合投屏展示

### 2. 自动刷新
- **按钮位置**：右上角 "🔄 刷新"
- **快捷键**：Ctrl+R
- **功能**：每30秒自动更新数据和图表
- **状态指示**：激活时按钮变为蓝色 "🔄 刷新中"

### 3. 快捷键支持
- **按钮**：右上角 "⌨️"
- **快捷键列表**：
  - `F11` - 全屏模式
  - `Ctrl+K` - 快速聚焦搜索框
  - `Ctrl+R` - 切换自动刷新
  - `Ctrl+E` - 导出PDF报告
  - `Esc` - 关闭所有打开的面板

## 🔧 数据管理功能

### 1. 自定义统计项目 ⭐核心功能
**位置**：数据洞察栏 → "🎯 自定义统计项目"

**功能说明**：
- 可以选择任意1-18个项目进行汇总统计
- 影响KPI卡片：总净胜分、日胜率、最长连胜、单日极值

**快捷操作**：
- **全选** - 选择所有18个项目
- **清空** - 取消所有选择
- **仅TOP5** - 快速选择当前排名前5
- **高价货** - 快速选择货价≥400的项目

**使用场景**：
```
场景1：只看自己买的货
- 清空 → 勾选"老尾"+"新尾" → 应用
- KPI显示：仅这两个货的汇总数据

场景2：对比高价货 vs 全部
- 先看全部数据 → 点击"高价货" → 应用
- 对比前后KPI变化

场景3：排除亏损项目
- 清空 → 手动勾选盈利项目 → 应用
- 查看纯盈利组合的表现
```

### 2. 项目对比分析
**位置**：点击 "📊 对比模式"

**功能**：
- 选择两个项目进行详细对比
- 对比维度：净胜分、胜率、场均、ROI、货价
- 自动给出对比结论

### 3. 数据录入
**位置**：右下角浮动按钮 "+" 或工具栏 "+ 录入"

**功能**：
- 选择日期
- 粘贴备忘录格式文本（如：老尾+1 新尾-2）
- 点击"识别填入"自动解析
- 点击"保存更新"存储到本地

### 4. 数据导入导出
**导出备份**：
- 按钮：💾 备份
- 格式：JSON文件
- 文件名：蛇货战绩备份_日期.json

**导入备份**：
- 按钮：📂 导入
- 支持：之前导出的JSON文件

**导出PDF报告** ⭐新功能：
- 按钮：📄 导出报告
- 快捷键：Ctrl+E
- 格式：PDF文件，包含完整图表
- 文件名：蛇货战绩报告_日期.pdf
- **注意**：首次使用需要等待3-5秒生成

## 🆘 常见问题

### Q: 刷新后数据还在吗？
A: 在！数据保存在浏览器LocalStorage，除非清理浏览器缓存。

### Q: 可以在手机上用吗？
A: 可以！界面自动适配手机屏幕。

### Q: PDF导出失败怎么办？
A: 稍等几秒重试，或尝试缩小浏览器窗口后再导出。

### Q: 可以导出Excel吗？
A: 目前支持PDF和JSON，如需Excel可以从JSON转换。

### Q: 数据会同步到云端吗？
A: 不会，所有数据仅保存在本地浏览器。

### Q: 自定义项目后排名表也变了吗？
A: 不会，排名表始终显示全部18个项目。自定义只影响KPI卡片。
