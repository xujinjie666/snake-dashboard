**位置**：数据洞察栏
**功能**：
- 基于最近7天数据预测趋势
- 三种预测结果：
  - 📈 上升趋势（斜率 > 0.5）
  - 📉 下降趋势（斜率 < -0.5）
  - ➡️ 平稳趋势

**算法**：
```
使用最小二乘法线性回归
分析最近7天数据的趋势线斜率
```

#### 5. ⚠️ 风险评估系统
**位置**：数据洞察栏
**评估维度**：
- 计算日波动率（标准差）
- 三个风险等级：

| 等级 | 波动率 | 颜色 | 说明 |
|------|--------|------|------|
| 低 | <2 | 绿色 | 波动较小，风险可控 |
| 中 | 2-5 | 黄色 | 波动适中，注意控制 |
| 高 | >5 | 红色 | 波动较大，风险较高 |

#### 核心算法

**1. 线性回归趋势预测**
```javascript
// 计算斜率
slope = (n*Σ(xy) - Σx*Σy) / (n*Σ(x²) - (Σx)²)

// 判断趋势
if(slope > 0.5) → 上升趋势
if(slope < -0.5) → 下降趋势
else → 平稳趋势
```

**2. 风险评估（方差/标准差）**
```javascript
// 计算波动率
avg = Σvalue / n
variance = Σ(value - avg)² / n
volatility = √variance

// 风险等级
if(volatility > 5) → 高风险
if(volatility > 2) → 中风险
else → 低风险
```

**3. 预警检测**
```javascript
// 连续亏损检测
recent3 = dailyTotals.slice(-3)
if(recent3.every(v => v < 0)) → 预警

// 大额亏损检测
if(today < -10) → 预警
```
