## 📖 使用教程

### 1️⃣ 录入数据
```
1. 点击右下角 "+" 或工具栏 "+ 录入"
2. 选择日期
3. 粘贴数据（格式：老尾+1 新尾-2 木同+3）
4. 点击 "识别填入" → "保存更新"
```

### 2️⃣ 自定义统计
```
1. 点击 "🎯 自定义统计项目" 下拉按钮
2. 勾选想要分析的项目
3. 点击 "应用"
4. KPI卡片实时更新
```

### 3️⃣ 查看明细
```
方式1：点击饼图中的项目
方式2：点击排名表中的 "详情" 按钮

→ 弹窗显示完整统计+走势图
```

### 4️⃣ 导出数据
```
💾 全量备份：导出所有数据JSON
📦 导出数据：选择月份导出JSON
📄 导出PDF：整页截图报告（Ctrl+E）
📊 导出CSV：月度明细表格
```

### 5️⃣ 月度明细
```
1. 滚动到页面底部
2. 点击 "8月/9月/10月" 切换月份
3. 查看每天每个项目的得分
4. 点击 "📊 导出CSV" 导出Excel
```

## 🔥 亮点功能

### 1. 智能月份识别 🆕
- **自动识别**所有有数据的月份
- **自动适配**新月份（11月、12月...）
- **无需修改代码**，永久有效

### 2. 智能备份提醒 🆕
- **自动检测**上次备份时间
- **超过7天**自动提醒
- **防止数据丢失**

### 3. 数据钻取
- 点击饼图 → 查看项目详情
- 点击详情按钮 → 完整统计
- 包含走势图、连胜记录、ROI

### 4. 趋势预测
- 基于最近7天数据
- 线性回归算法
- 预测上升/下降/平稳趋势

### 5. 风险评估
- 计算日波动率
- 三个风险等级：高/中/低
- 辅助投资决策
